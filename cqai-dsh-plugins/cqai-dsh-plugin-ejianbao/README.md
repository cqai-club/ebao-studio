# e剪宝

统一的视频工作区。侧栏只保留一个 e剪宝入口，内部通过「数字人视频制作」「短视频制作」「口播视频制作」三个标签切换。

依赖三个现有制作插件和 `cqai-dsh-media-settings`。聚合启用时隐藏三个独立侧栏入口，旧 main 地址转到对应标签；聚合停用后恢复独立入口。页面通过 `ejianbao.workspace` 公共插槽贡献，不跨插件导入私有组件。

标签第一次访问时挂载；切换后保留草稿、文件和编辑工作台，并暂停隐藏页的客户端轮询。制作任务仍由原插件执行。

公共设置使用 Credentials 保存素材密钥，界面只返回连接状态；公共默认画幅与 Edge 音色只作用于新短视频/口播草稿。已有任务和数字人视频制作的横版输出保留原参数。原配置不同的功能保留覆盖值，可在设置中明确恢复公共值。

制作环境先展示公共工具卡，统一检查和安装/修复共享 Python 3.11、FFmpeg 与 ffprobe，并检查内置 uv 和宿主 Node.js。下方三个功能卡只展示各自的 Python 包环境、渲染、配音和字幕等专属依赖；安装范围在卡片中说明。任何一次准备完成或失败后都会重新检查公共工具与全部功能，失败可重试，运行日志默认收起。

各功能安装会复用公共工具，缺少时自动准备，已就绪时跳过，无需先点击公共卡。数字人视频随后安装本功能的 Python 包；现有渲染引擎仍需在该插件的 `runtime/render-studio` 目录运行 `npm ci`。指定工具可通过 `EJIANBAO_PYTHON`、`FFMPEG_PATH`、`EJIANBAO_BROWSER_EXECUTABLE` 配置，随后重启应用并重新检查。

运行 `corepack yarn workspace cqai-dsh-plugin-ejianbao typecheck`、`test`、`build` 验证。构建生成插件产物，不启动图形应用。
