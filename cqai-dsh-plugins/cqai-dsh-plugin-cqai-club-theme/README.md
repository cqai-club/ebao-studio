# CQAI Club 主题

这个 Desktop 客户端插件为 DSH 提供黑白灰默认色板，并内置「中国红」「科技蓝」「卡通温馨」三套可切换预设。扩展模式和增强模式加载插件后自动应用；兼容模式继续使用上游默认界面。

浅色、深色和跟随系统仍由原有「外观」设置控制。四种风格在明暗模式下分别提供背景、卡片、侧栏、边框、文字、按钮、链接和焦点颜色。空会话首页背景统一铺在 Desktop 框架上，连续覆盖侧边栏与会话区。经典黑白使用浅蓝／深蓝灰 CSS 雾面渐变，侧边栏与数字员工区域标题采用半透明磨砂面板；标题区加入低对比弧线、细点阵和更明确的字级。中国红使用五星红旗、长城和华表构图；科技蓝和卡通温馨各有一对同构图的浅色／深色 WebP 背景。这些图片随插件打包，无运行时图片下载。背景不会进入普通对话和 PPT 模板面板，并在强制高对比度模式下隐藏。它不替换业务页面，也不改变用户的外观偏好。

## 外观设置

打开「设置 → 通用」，在原有外观和字号设置后找到「CQAI Club 主题」。点击风格卡片即可切换经典黑白、中国红、科技蓝或卡通温馨，并同步应用对应色板与空会话首页背景。经典黑白可在「浅蓝雾面」与「纯色（无磨砂）」之间切换；其他风格可选择内置背景或纯色，也都可以上传自定义图片。背景仅用于空会话首页。上传支持 PNG、JPG、WebP 和 AVIF，插件会缩小并转成 WebP 后保存在本机。图片不会上传到服务器。

主题色可用取色器、HEX 颜色值或预设色调整；手动改色不会取消已选风格。按钮、链接和焦点色会立即跟随，浅色和深色模式会各自调整为可读的颜色。「恢复主题默认值」会清除已保存的自定义图片与配色，回到浅蓝雾面背景及黑白灰色板。旧版保存的自定义主题色和背景会继续保留，新增的风格默认为经典黑白；选择其他风格后也能重新启用先前上传的图片。设置使用此 Desktop 界面的本地存储，重启后仍生效。

背景原图、生成提示词及压缩方式见 [assets/README.md](./assets/README.md)。

插件包名：`cqai-dsh-plugin-cqai-club-theme`。可独立安装；Beta 和 Stable 的默认 Desktop 产品组合会包含它。

## 开发版启用

新增插件后需要退出旧的 Electron 开发进程，再用原来的 `DSH_HOME` 和 `DSH_DESKTOP_DEV_USER_DATA` 运行 `corepack.cmd yarn dev:beta`。单独执行构建不会把插件注入正在运行的 Profile。重启后可以在当前 DSH home 的 `profiles/desktop/package.json` 中检查 `dsh.profile.bundles` 是否包含本插件，并在插件管理中确认其状态为启用。
