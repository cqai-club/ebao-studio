## 中国红

浅色编辑提示词：沿用朱红绸缎、金色线条与暖象牙色中央留白；在左上加入一面有一大四小共五颗金星的五星红旗，在左下加入延伸入远山的长城，在最右侧加入一根雕龙纹与云纹的白色华表。调整旗帜位置，使五颗星落在侧边栏右侧、完整可见。深色编辑提示词：保留旗帜、五颗星、长城、华表及原构图；将中央改为安静的深酒红与暖炭色，让长城呈暮色、华表有柔和暖光，旗面仍保持清晰的红金配色。

## 科技蓝

浅色生成提示词：钴蓝和宝石蓝的半透明玻璃曲线、青色光纤细线和边缘的精细网格；中央大面积淡蓝白留白，干净且具有现代科技感。深色编辑提示词：保持玻璃曲线、青色导光线与边缘网格构图，将中央换为安静的午夜海军蓝，边缘光线明亮但克制。

## 卡通温馨

浅色生成提示词：手绘纸张质感、柔软的云朵状圆形、蜜桃珊瑚色与奶油黄，少量薄荷绿和浅紫色；颜色主要在边缘，中央奶油白留白，温暖而不过度幼稚。深色编辑提示词：保持云朵和边缘小花园的形状，将中央换为深梅紫炭色，边缘改为暖调暮色中的蜜桃、珊瑚、赭黄、薰衣草紫和鼠尾草绿。
