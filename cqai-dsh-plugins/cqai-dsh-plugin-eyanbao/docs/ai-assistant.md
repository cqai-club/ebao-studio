# AI 研究助手

AI 研究助手位于研究任务栏左侧，围绕当前研究需求提供四种短任务：

- **优化需求**：把当前描述改写为一句更清晰、可执行的研究问题。
- **检索词**：生成中文关键词、英文关键词和布尔检索式。
- **研究方法**：推荐研究设计、材料来源、分析步骤、效度或可信度、伦理风险和局限。
- **论文提纲**：按当前任务类型和学位层次生成章节结构。

助手使用 DSH 当前默认文字模型，结果以流式方式显示并可在生成中停止。建议不会自动写入文献来源，也不会被当作证据；用户可以替换或追加到研究需求后继续检索和写作。

交互要求：按钮具备可访问名称，`Esc` 关闭浮层，关闭后焦点返回触发按钮，移动端浮层限制在当前视口内。
