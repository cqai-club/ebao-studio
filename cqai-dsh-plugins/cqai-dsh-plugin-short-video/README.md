# 短视频制作

独立的 DSH Cordis 插件，使用 MoneyPrinterTurbo 1.3.7 的视频流水线。制作页面沿用易宝工坊的控件和主题；与“e剪宝”是两个插件、两个任务目录。

## 第一阶段功能

- 按“主题与文案 → 素材与画面 → 声音 → 字幕 → 制作”操作。可预览提示词、生成或自写文案与关键词；声音试听为可选步骤。
- Pexels、Pixabay、Coverr 素材检索；本地视频/图片上传；CQAI Club 图片模型生成画面，或使用账号的视频模型逐段生成视频素材。
- Edge TTS 声音与音量/语速，上传旁白，关闭/随机/上传背景音乐。
- 字幕开关、整句/逐字、动画、位置、系统字体、颜色、字号、描边。
- 画幅、裁切/适配、镜头时长/速度、随机/顺序、转场、生成数量与编码器。
- 分阶段制作文案、关键词、配音、字幕、素材或成片；本机持久化任务、取消、重做、下载和视频预览。
- “历史任务”按整条制作流程计数；“新增”开启空白流程，配音试听、失败后的重做和最终成片归在同一条历史记录中。选中历史任务会还原保存的参数、文案、关键词、配音、素材来源和字幕到对应步骤；仍在本机的素材可预览和下载，浏览器不会自动重新选择本地上传文件。历史记录可删除整条流程及其本地任务文件，运行中的流程须先完成或取消。旧记录只依据已有的配音关联归并，不会仅凭相同主题合并。
- 创作预设 JSON 导入/导出、素材平台密钥、运行环境检查和安装。

文本、图片和视频模型均来自当前登录的 CQAI Club 账号。服务端创建任务及模型调用前都会检查模型目录；脚本请求通过 DSH LLM 服务发送，图片和视频请求通过账号服务发送。插件不另存 CQAI API Key，也不暴露本地 Python HTTP 服务。若素材来自其它平台，该平台仍需要自己的素材 API Key。

“素材与画面”可选择账号目录中的视频模型，包括 `wan3.0-video-480p`。CQAI 视频默认按每条成片 30 秒规划镜头；页面显示按单镜头时长和成片数量计算的镜头数，用户确认后才逐镜头提交。Host 使用统一的 `POST /v1/videos`、`GET /v1/videos/{id}`、`GET /v1/videos/{id}/content` 接口生成、查询并下载 MP4。镜头及远端任务 ID 保存在素材任务中，后续制作引用已完成任务；网络错误使提交结果不确定时，原任务不会自动再次提交。参数改变后须再次确认并生成素材。视频模型实际时长和画幅限制由服务端校验，成片实际时长也取决于返回素材。

主题由用户填写；此处的 AI 操作是根据主题生成文案和关键词。文案与关键词会回填为可编辑内容，后续制作使用校对后的文本。提示词预览、生成和关键词提取调用随插件打包的 MoneyPrinterTurbo 逻辑。

声音页可选“使用视频原声”“稍后生成配音”“上传旁白”。视频原声只用于 CQAI 视频；没有音轨的镜头填充静音，不自动配音。上传旁白可直接提交最终任务。可选的配音试听仍可复用音频，Edge TTS 时间轴保存在任务私有目录。

字幕页可按每条成片预览和修改 SRT，保存时校验时间范围。上传旁白与视频原声使用 Whisper 识别实际语音，不用文案替换识别结果；无可识别语音时可制作无字幕视频。原声视频按实际剪辑顺序同步处理音画。目标时长是素材预算上限，素材不足时显示实际时长，不自动购买更多镜头。制作任务引用的素材、声音和字幕可复用；被引用的任务需先删除后续任务才能删除。

## 使用

在易宝工坊仓库根目录启动开发版（Git Bash）：

```bash
DSH_AA_SOURCE_REF=pinned corepack yarn dev
```

默认 `desktop` Profile 同时包含“e剪宝”和“短视频制作”，并使用当前 `DSH_HOME` 的登录状态和任务数据。`DSH_AA_SOURCE_REF=pinned` 复用已校验的 Agents Anywhere 包；如果使用新的 `DSH_HOME`，需要在该目录重新登录 CQAI Club。

首次打开“设置”页，点击“安装 / 修复依赖”。需要本机有 Python 3.11+、uv 和 FFmpeg；安装使用随插件附带的 uv.lock，把 Python 环境放在 DSH_HOME/short-video/engine/.venv，可能下载较大的语音识别和视频依赖。素材与任务位于 DSH_HOME/short-video/。可以用 MPT_PYTHON 环境变量指定已准备的 Python 解释器。

原仓库的其它付费 AI 视频提供商、专有 TTS/音乐模型、Upload-Post 自动发布、云端批量脚本报价尚未接入此插件。CQAI Club 视频生成会在开始制作前提示按镜头计费。字幕使用本机系统字体；原仓库附带的字体与歌曲不在插件包内。
