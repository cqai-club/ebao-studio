# TalkCraft 普通用户版界面草图（V2）

> 这套 Markdown 线框图是 TalkCraft 插件界面改造的设计依据，覆盖从创建到交付的全部页面。TalkCraft 仍是独立插件。

## 核心思路

用户来这里是想做出一条视频。首页回答“我有哪些视频、下一步做什么”；新建流程只问三件事：**说什么、用什么声音、用什么画面**。制作完成后才提供精细编辑。

```text
首页 → 写文案 → 选声音 → 添画面 → 开始制作
                            ↓
          看画面安排 → 看试片 → 看成片 → 精细编辑（可选）
```

### 页面用语

| 当前内部称呼 | 页面上显示 |
| --- | --- |
| SHOTBOOK、分镜脚本 | 画面安排；详情中可查看分镜脚本 |
| 有声样板镜 | 试片；说明“先看一小段成片效果” |
| 素材候选 | 可选画面素材 |
| 字级对齐、ASR | 匹配配音与文案 |
| Fish Audio | AI 配音；在说明中注明服务商 |
| Pexels、Pixabay | 在线找素材；在素材详情中注明来源 |
| 多轨工作台 | 精细编辑；副标题“调整镜头、文字和节奏” |

## 1. 首页：我的视频

首页不展示空白表单。未完成的用户决策排最前，其余视频按最近使用排序。右上角一个明显的“做新视频”按钮；设置用齿轮进入。
“最近的视频”卡片把打开和删除分成两个按钮。删除需二次确认，说明本机配音、素材、分镜和成片会一起删除；制作中的任务先停止再清理。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ TalkCraft 口播视频                                  [? 帮助] [⚙ 设置]           │
│ 我的视频                                             [＋ 做新视频]             │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  需要你处理                                                    1 项            │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 🎬 徒步是什么       画面安排已做好，等你看一眼           [去确认 →]      │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                │
│  最近的视频                                                                    │
│  ┌──────────────────────┐ ┌──────────────────────┐ ┌──────────────────────┐  │
│  │ 封面／画幅预览        │ │ 封面／画幅预览        │ │ 封面／画幅预览        │  │
│  │ 徒步是什么           │ │ 周末去海边           │ │ 城市散步             │  │
│  │ 制作中 · 正在做试片   │ │ 已完成               │ │ 已暂停，可继续       │  │
│  │ [查看进度]           │ │ [播放] [下载]        │ │ [继续制作]           │  │
│  └──────────────────────┘ └──────────────────────┘ └──────────────────────┘  │
│                                                                                │
│  [查看全部视频]                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

首次使用的空状态只显示一句引导和主按钮：“把一段口播稿变成视频。你可以上传自己的配音和照片。”

## 2. 新建 · 第一步：说什么

用一个专注页面写文案。标题可以根据文案第一句自动建议，仍可手动改。始终能返回上一步，已输入内容自动保留。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 我的视频                         新建视频     ① 文案 — ② 声音 — ③ 画面    │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  这条视频想说什么？                                                            │
│  把口播稿贴在这里。接下来会根据每句话安排画面。                                │
│                                                                                │
│  视频名称（可改）                                                              │
│  [徒步是什么______________________________________________________________]  │
│                                                                                │
│  口播稿                                                                        │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │ 很多人问，徒步到底是什么？                                               │  │
│  │ 其实徒步没有那么复杂……                                                   │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│  219 字 · 建议与配音说的话一致                                                 │
│                                                                                │
│                                                       [下一步：选择声音 →]     │
└────────────────────────────────────────────────────────────────────────────────┘
```

缺文案时，按钮附近写“先填写口播稿”，不让用户猜为什么按钮是灰的。

## 3. 新建 · 第二步：选声音

先让用户选来源，再显示对应控件。上传文件后可以直接试听；如果选 AI 配音，缺少密钥时给出就地配置入口。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 返回文案                       新建视频     ① 文案 — ② 声音 — ③ 画面     │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  视频用什么声音？                                                              │
│  ┌───────────────────────────────┐  ┌───────────────────────────────┐         │
│  │ ● 我已经录好了                │  │ ○ 帮我生成配音                │         │
│  │   上传成品配音，保持原声      │  │   使用 AI 配音服务            │         │
│  └───────────────────────────────┘  └───────────────────────────────┘         │
│                                                                                │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │  拖入音频，或 [选择音频文件]                                             │  │
│  │  支持 MP3、WAV、M4A 等                                                  │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                │
│  已选择：标准录音 4.mp3   00:52     [▶ 试听] [换一个] [移除]                  │
│  提示：声音和文案不同的地方，后续字幕可能对不上。                              │
│                                                                                │
│                                        [返回] [下一步：添加画面 →]             │
└────────────────────────────────────────────────────────────────────────────────┘
```

选择“帮我生成配音”时，此处换成服务状态与说明。页面写“开始制作时生成配音”，不暗示点击下一步就会发出付费请求。

## 4. 新建 · 第三步：添画面并开始

照片和视频使用同一素材区，用户可拖入多项。上传后展示缩略图并允许移除。画幅放在这一步，因为用户能同时判断自己的素材是否适合横屏或竖屏。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 返回声音                       新建视频     ① 文案 — ② 声音 — ③ 画面     │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  画面从哪里来？                                                                │
│  上传自己拍的照片、视频；需要时也可以让 TalkCraft 找在线素材。                  │
│                                                                                │
│  [＋ 添加照片或视频]     已加入 5 项                                            │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐         │
│  │ 缩略图       │ │ 缩略图       │ │ 缩略图       │ │  ＋           │         │
│  │ DJI_0206.JPG │ │ DJI_0208.JPG │ │ 海边.mov     │ │ 继续添加     │         │
│  │ [预览] [×]   │ │ [预览] [×]   │ │ [预览] [×]   │ │              │         │
│  └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘         │
│                                                                                │
│  没拍够画面？ [✓] 需要时找在线素材                                              │
│  人物出镜视频可以直接上传；此功能不会自动生成数字人。                            │
│                                                                                │
│  视频画幅       [● 横屏 16:9]   [○ 竖屏 9:16]                                  │
│                                                                                │
│  这次制作：219 字文案 · 已上传配音 00:52 · 5 项素材 · 横屏                       │
│  将先准备画面安排，完成后等你确认，再制作一段试片。                              │
│                                                                                │
│                                        [返回] [开始制作视频 →]                  │
└────────────────────────────────────────────────────────────────────────────────┘
```

如果开始条件缺失，只在按钮上方写出具体问题和解决入口，例如“还没有声音：上传配音，或设置 AI 配音”。环境命令不出现在这个页面。

## 5. 制作进度：现在做到哪了

进度页显示**真实阶段、持续时间和最近一次活动**。用户可以离开页面，回来继续看。没有可靠进度数据时不显示虚假的百分比或“马上完成”。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 我的视频                 徒步是什么                          [停止制作]     │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│                    正在制作一段试片                                            │
│                    已等待 18 分钟 · 最近进展 2 分钟前                           │
│                                                                                │
│       ✓ 准备声音与素材   ✓ 安排画面   ● 制作试片   ○ 完成整条视频               │
│                                                                                │
│  当前在做：整理第一段画面和配音。完成后会请你试看。                              │
│  已完成的文案、素材和画面安排会保留。                                            │
│                                                                                │
│  [查看画面安排]    [▸ 查看详细记录]                                             │
│  你可以先去做别的事，稍后从“我的视频”回到这里。                                  │
└────────────────────────────────────────────────────────────────────────────────┘
```

**已暂停／失败**沿用同一页：主标题变成“制作暂停了”，显示一句可读原因和 `[从上次进度继续]`；报错堆栈只在“详细记录”里。停止制作时写明“已完成的内容会保留”。

## 6. 第一次确认：画面安排

用户要判断的是“讲到这句话时用什么画面”。每段展示旁白、预计时间和对应素材。这里的缩略图明确标为**素材预览**，不能冒充已经渲染好的镜头。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 我的视频       徒步是什么 / 看看画面安排                                    │
│ 已安排 11 段画面；确认后开始制作一段试片。                                     │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  01  很多人问，徒步到底是什么？                          0:00—0:02           │
│  ┌──────────────────┐  海边人物，缓慢靠近；标题跟随旁白出现。                  │
│  │ 素材预览         │  DJI_0206.JPG · 我上传的照片                           │
│  └──────────────────┘  [查看这段的详细安排]                                   │
│  ──────────────────────────────────────────────────────────────────────────    │
│  02  其实徒步没有那么复杂……                              0:02—0:08           │
│  ┌──────────────────┐  人物站在海边；减少文字遮挡。                           │
│  │ 素材预览         │  DJI_0208.JPG · 我上传的照片                           │
│  └──────────────────┘  [换一份素材] [查看这段的详细安排]                      │
│  ──────────────────────────────────────────────────────────────────────────    │
│  03  ……                                                                       │
│                                                                                │
│  [查看完整分镜脚本]   [查看全部素材来源]                                       │

│  这套画面安排可以吗？         [我想调整]       [可以，制作试片 →]            │
└────────────────────────────────────────────────────────────────────────────────┘
```

点击“我想调整”后才展开意见区，给三个可选快捷表达：`多用我上传的画面`、`文字少一些`、`节奏慢一些`，下方仍有自由输入。提交前显示本次修改范围是“重新安排画面”。在线素材点击后显示作者、来源链接和选用状态。

## 7. 第二次确认：试看一小段

试片视频占主要空间，播放控件由用户熟悉的方式呈现。用户先看，再做“满意／调整”决定。这里不把工作台编辑暴露为必经步骤。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 我的视频       徒步是什么 / 试看一小段                                      │
│ 这是开头的一段，带有配音。满意后继续制作完整视频。                              │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                          │  │
│  │                        有声试片播放器                                    │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│  [▶ 重播]  [调节音量]  [全屏]  [下载试片]                                      │
│                                                                                │
│  对应旁白：很多人问，徒步到底是什么？                                           │
│  [▸ 查看使用的素材和镜头说明]                                                  │
├────────────────────────────────────────────────────────────────────────────────┤
│  这段效果怎么样？               [我想调整]       [满意，继续完成 →]           │
└────────────────────────────────────────────────────────────────────────────────┘
```

“我想调整”展开常用意见：`画面不合适`、`字幕挡住人物`、`节奏太快`、`声音有问题`，并允许写具体要求。无法播放时保留下载入口和明确的失败原因。

## 8. 成片：播放、下载、继续编辑

完成页先满足最常见的“看一下、下载”。精细编辑是次级入口，适合有调整需求的用户。

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ ← 我的视频           徒步是什么                                      已完成    │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│  ┌──────────────────────────────────────────────────────────────────────────┐  │
│  │                                                                          │  │
│  │                            完整视频播放器                                │  │
│  │                                                                          │  │
│  └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                │
│  [下载视频 MP4]             [精细编辑镜头、文字和节奏 →]                       │
│                                                                                │
│  [▸ 其他文件]  分镜脚本、字幕时间轴、编辑后导出的版本                          │
│  [▸ 制作记录]                                                                 │
└────────────────────────────────────────────────────────────────────────────────┘
```

点击“精细编辑”进入全宽工作台承载页，页顶保留 `[← 返回视频]`。独立 TalkCraft 工作台继续管理多轨和导出，不接入 e剪宝。

## 9. 设置：只在需要时出现

设置从页头齿轮进入。普通用户首先看到“能否正常制作”；服务商名称、密钥和本地依赖在展开区域里。密钥删除必须是独立按钮，不用“清空后保存”的隐含操作。

│ ← 我的视频                            设置                                     │
├────────────────────────────────────────────────────────────────────────────────┤

## 窄窗口与视觉规范

- 窄窗口下所有页面单列排列；创建步骤保持顶部可见，主要按钮固定在页面底部。
- 视频与素材预览保持原画幅。确认页只有页面整体滚动，不在卡片中叠加滚动条。
- 背景、卡片、边框和文字沿用易宝工坊的 DSH 主题变量；整体以黑白灰为主，主操作使用当前主题的高对比中性色，错误提示保留必要的状态色。
- 页面标题约 22px、区块标题约 16px、正文约 13px；主按钮约 34px 高，常规按钮约 32px 高，选择卡片保留完整的可点击区域。
- 文件上传使用“拖入或选择文件”卡片；系统原生文件按钮不直接裸露在表单中。
- 状态主要用文字和阶段位置区分，错误提示用少量状态色；错误写“发生了什么、下一步能做什么”。

## 落地时需要补足的界面数据

1. 将现有 `SHOTBOOK.md` 与素材候选整理成“逐段画面卡片”；无对应缩略图时显示文字占位。
2. 保存创建流程的未提交输入，保证返回上一步和切换页面不会丢稿。
3. 提供可靠的最近活动时间；制作页只显示真实阶段，不推算百分比。
4. 把工作台入口作为完整页面承载，避免在窄任务详情卡中嵌入编辑器。

这四项是本草图依赖的界面改造点，不代表现有代码已经具备。
