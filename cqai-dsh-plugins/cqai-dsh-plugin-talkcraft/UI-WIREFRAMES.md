# TalkCraft 口播视频插件 · 界面重设计线框稿

> 讨论稿。对应当前独立 TalkCraft 插件的主界面；本文只画页面和交互，不改程序。多轨编辑器本身另有独立界面，这里只设计它在插件中的入口和承载页。

## 设计方向

- **任务优先**：进入插件先看到项目和待确认事项，创建新视频始终是显眼的主操作。
- **内容优先**：分镜、样板视频、成片占主区域；环境检查、日志和技术细节收在次要位置。
- **每一步都能判断**：等待时写明正在做什么、上次进展和可执行操作；确认时同时看到画面、素材来源和修改入口。
- **沿用桌面主题**：使用 DSH 的字号、间距、按钮和明暗主题变量；状态不能只靠颜色区分。
- **保持插件独立**：页面只呈现 TalkCraft 任务、素材和设置，不混用 e剪宝的项目或入口。

### 页面关系

```text
项目列表 ── 新建视频 ── 制作中 ── 确认分镜 ── 确认有声样板镜 ── 成片交付
   │                        │             │                 │              │
   ├── 已中断／失败 ── 继续制作／查看原因     └── 退回修改       └── 多轨工作台
   └── 服务设置
```

## 0. 通用页框

导航占一行，页面标题跟随当前任务状态变化；“独立插件”不需要长期占据最显眼的位置，可以放在插件说明里。

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│  ◉ TalkCraft 口播视频                       本地服务：正常  ·  查看环境           │
│  [项目 3]    [＋ 新建视频]    [服务设置]                                       │
├──────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  当前页面标题                                      当前页面的主操作               │
│  一句话说明当前应做什么                                                           │
│                                                                                  │
│  页面内容                                                                        │
└──────────────────────────────────────────────────────────────────────────────────┘
```

桌面内容最大宽度约 1360px，左右留白随窗口变化。任务详情不再固定为 320px 宽；320px 只适合项目列表、检查摘要等辅助栏。

## 3. 制作中／中断／失败

同一任务详情根据状态切换主卡片。不要给没有可靠计算依据的进度百分比；改为真实阶段和最近活动。

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│  徒步是什么  /  有声样板镜                                  [取消任务]          │
│  已运行 18 分钟 · 最近活动：17:39 · 正在生成 s01 镜头                          │
│                                                                                  │
│  [✓ 配音与对齐] ─ [✓ 分镜] ─ [● 有声样板镜] ─ [○ 完整成片] ─ [○ 独立审片]       │
│                                                                                  │
│  当前步骤                                                                        │
│  正在生成有声样板镜。完成后会停在“确认样板镜”，等待你检查画面和配音。              │
│  最近进展：读取镜头素材 → 生成镜头代码 → 渲染 → 检查音视频流                        │
│                                                                                  │
│  [查看分镜]  [查看素材]  [▸ 展开完整日志]                                     │
└──────────────────────────────────────────────────────────────────────────────────┘
```

- **已中断**：显示最后成功阶段、可恢复文件和 `[继续制作]`；不沿用“制作中”的动画。
- **失败**：把可读的原因放在主卡片，技术堆栈放日志；显示 `[重试本阶段]`（若实际操作仍为“继续制作”，按钮文案与后端保持一致）。
- **取消**：只取消当前运行，不隐藏项目和产物；任务仍可从已验证阶段继续。

## 4. 确认分镜与素材

这是第一处决策停点。正文不再塞进 180px 高的 `pre` 滚动框；默认按镜头展示，原始 SHOTBOOK 作为“查看全文／下载”入口。每个镜头应能看到所用素材及来源。

```text
│  徒步是什么  /  确认分镜                                  [查看 SHOTBOOK 全文] │
│  共 11 镜 · 约 52 秒 · 声音：已上传配音                                           │
├───────────────────┬──────────────────────────────────────────────────────────────┤
│  镜头导航         │  S01  开场提问                         0:00—0:02          │
```

## 5. 确认有声样板镜

第二处决策停点应让视频成为主角。右侧放“对照信息”和意见，按钮固定在底部，避免用户看完视频还要滚动很远。

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│  徒步是什么  /  确认有声样板镜                                                  │
│  这是第一镜的有声试看；确认后才继续制作其余镜头。                                │
├─────────────────────────────────────────────────────────┬────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐│  对照信息              │
│  │                                                     ││  镜头：S01             │
│  │          视频预览（带播放、音量和全屏）               ││  对应旁白：……          │
│  │                                                     ││  使用素材：DJI_0206    │
│  └─────────────────────────────────────────────────────┘│  来源：用户上传        │
│  [重新播放]  [下载样板镜]                                │                        │
│                                                         │  修改意见              │
│                                                         │  ┌──────────────────┐  │
│                                                         │  │ 需要调整时填写…  │  │
│                                                         │  └──────────────────┘  │
├─────────────────────────────────────────────────────────┴────────────────────────┤
```

样板镜的预览必须明确含音频；若浏览器无法播放，应显示文件下载与具体错误。退回意见只针对样板镜，不混入分镜确认意见。

## 7. 服务设置与制作环境

服务分卡展示，密钥仅显示“已配置／未配置”。清除密钥使用独立的“移除密钥”操作，避免“空输入框点保存就删除”的歧义。

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│  服务设置                                                                        │
│  密钥保存在本机 DSH Credentials。                                                │
├──────────────────────────┬──────────────────────────┬────────────────────────────┤
│  Fish Audio              │  Pexels                  │  Pixabay                   │
│  配音服务 · 已配置        │  视频/图片 · 已配置       │  图片/视频 · 未配置         │
│  [更换密钥] [移除密钥]    │  [更换密钥] [移除密钥]    │  [配置密钥]                │
└──────────────────────────┴──────────────────────────┴────────────────────────────┘
┌──────────────────────────────────────────────────────────────────────────────────┐
│  本地制作环境                                            [重新检查]              │
│  ✓ Node  ✓ Python  ✓ FFmpeg  ✓ Remotion  ✓ 浏览器  ✓ 字级对齐模型              │
```

若某项缺失，展示“缺什么 → 怎么准备 → 重新检查”；正常时压缩成一行，不占新建视频页面的一整列。

## 8. 插件内多轨工作台承载页

用户从已确认样板镜或已完成任务进入。插件外框保留任务定位和返回操作，工作台区域使用全宽、足够高度。切换任务前关闭旧工作台服务。

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│  ← 返回「徒步是什么」    多轨工作台                 [打开独立窗口] [关闭工作台] │
├──────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│                    嵌入的 TalkCraft 多轨工作台（全宽）                           │
│                    素材库 │ 预览 │ 属性                                        │
│                    ─────── 多轨时间轴 ───────                                  │
│                                                                                  │
└──────────────────────────────────────────────────────────────────────────────────┘
```

此页只重设计插件容器；实际多轨编辑器的卡片库、预览和时间轴视觉样式可另开一份设计稿。

## 窄窗口规则

```text
桌面宽屏：列表／辅助信息在左或右，主要内容占最大宽度。
窗口变窄：单列排列；项目列表先于详情，分镜镜头导航变横向滚动标签。
确认页面：底部操作栏始终可见；视频保持原画幅，不被侧栏压缩。
工作台：优先“在独立窗口打开”，避免在窄 iframe 内编辑时间轴。
```

## 设计确认点

1. 默认入口改为“项目列表”，新建视频通过突出按钮进入。
2. 任务详情占主区域；两次确认各用完整页面。
3. 本地依赖与命令放服务设置，创建页只显示能否开工及缺项。
4. 多轨工作台采用全宽承载页，不嵌在任务详情卡片下方。

这四项确认后，再绘制高保真视觉稿和实际组件规格。
