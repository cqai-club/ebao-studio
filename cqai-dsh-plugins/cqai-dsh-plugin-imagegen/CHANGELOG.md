# Changelog

## Unreleased

- 「全部生图」瀑布流按结果区宽度自适应列数，缩小卡片并保留图片完整比例，超宽窗口可展示更多列；窄区筛选和操作栏自动换行。
- 普通生图恢复「全部生图」汇总，不按来源过滤，补齐电商历次尝试、画布生成与图库保留结果；保留各模式管理和清理范围。
- 技能安装识别仓库内嵌套的单个技能及明确指定的 GitHub 目录，多个候选时要求指定目录；完整保留安装失败原因并显示在技能库窗口，避免只报 HTTP 200。
- 每张电商结果图新增常驻的「查看提示词」入口及复制，绑定该图成功生成时的实际请求；重生成期间旧图保留旧版本提示词，旧记录缺失版本时明确标注。
- 电商重新生成按分组锁定，其他已结束分组仍可重试；并行响应保持最新进度，同组重复点击不重复提交，取消任务后停止尚未发出的组内重试。
- 电商主表单输入控件统一为 13px，与普通生图保持一致，避免继承页面默认字号而显得过大。
- 电商套图与画布生成历史分别检索和清理，增加 Host 删除范围保护；普通生图默认汇总全部来源。
- 电商结果区新增「新建商品」旁的历史任务列表，恢复完整配置、参考图、结果与执行进度；旧任务如实展示缺失配置。
- 电商整套计划改由 Host 持久化与编排，保存重试依据，界面切换不影响后续生成；读取历史不触发生成。
- 集成上游 PNG 类型修复、Dock 稳定性、模型目录检测兼容和历史/图库图片懒加载。
- 画布 Dock 适配窄窗口换行、窗口缩放和减少动态效果设置，避免工具与缩放控件遮挡。
- 任务轮询改为轻量摘要，完成结果按需读取，保留多模型对比与电商主图锚定流程。
- 无限画布支持持久化收藏，以及图片全屏预览、缩放和重置。
- 电商套图按用途和图片序号生成不同构图提示词，每张图片支持单独 AI 润色与恢复默认。
- 新增 Handraw、Prompt Signal、EvoLink 三个社区模板来源，共 1,480 个案例；保留旧模板 ID、收藏键与数据目录兼容，补充第三方声明。

## 0.1.0 - 2026-09-14

- 首次发布 e图宝，提供文生图、图生图、多模型对比、电商模式、任务队列、历史、素材库、模板和无限画布。
- 内置 CQAI 默认 Provider，复用 CQAI Club 登录、额度与账号模型目录；第三方渠道仅在用户明确选择时使用。
- 接入 DSH 0.1.5 主区、侧边栏、会话附件、`/edit_image` 与 Agent 图像工具。
- 将 API Key、S3 与技能密钥保存在 Host Credentials 中，并为本地画布技能提供短期受限图像接口凭据。
- 兼容 `~/.dsh/dsh-imagegen` 旧数据并提供备份后的原子迁移；移除原插件自更新器。
- 普通生图采用右侧瀑布流任务记录；素材库和无限画布不显示独立历史栏。
