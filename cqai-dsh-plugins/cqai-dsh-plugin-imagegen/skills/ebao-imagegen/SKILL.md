# e图宝

只处理当前用户明确提出的图像操作。先明确要生成还是编辑、图片用途和必要的内容；缺少关键输入时简短询问，不自行提交任务。普通图片理解和提示词写作无需生图工具。

## 选择模型

首次执行图像操作或用户询问模型时，调用 `list_image_generation_models` 获取当前账号状态、模型和默认值。模型目录按需刷新，不使用过去对话中的目录代替当前结果。工具只返回公开模型信息，不返回凭据。

- 默认 Provider 是 `cqai`。省略模型时使用账号有效默认模型；只有一个可用模型时自动选择；多个模型没有有效默认值时询问用户。
- 指定模型只影响本次任务，不修改账号默认设置。
- 第三方渠道必须由用户明确选择，用返回的 `custom:<channelId>` 作为 `provider`。CQAI 登录、额度或请求失败时报告原因，不自动切换第三方。

## 执行

- 生成：`generate_image`，传入提示词和用户明确指定的模型、比例等参数。
- 编辑：`edit_image`，传入编辑要求和 `source_image`。使用用户上传、生图结果或读取图片工具返回的有效完整引用；缺少引用时先取得图片，不猜测引用或本地路径。
- 默认等待任务完成。用户明确要求后台执行时才设置 `wait_for_completion: false`，返回任务编号和状态。
- 结果通过原生图片附件展示，文字中简述完成情况。工具的文本结果保持结构化任务信息，图片附件位于结果元数据；不要把图片字节、访问凭据或巨大的内联图片写进文本。

## 查询和取消

`get_image_generation_task` 查询已知任务编号；`cancel_image_generation_task` 取消用户指定的任务。工具和工作台共用队列与历史，结果可进入图库或画布。查询按需进行，避免高频轮询。超时不代表失败；已有任务先查询，不重复提交。失败或取消要如实报告，仅在用户要求时重试。

生成和编辑可能消耗账号额度。用户明确请求图像操作即可执行；没有操作需求时不调用工具。工作台和画布仍可直接使用各自的生图入口。
