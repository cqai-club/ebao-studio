# 编辑当前本地草稿

读取本 Skill 后，下一步获得当前绑定草稿的编辑工具。先调用 `publisher_get_current_draft`；没有绑定时停止，不能选用其他草稿。只编辑绑定稿，不登记外部 Markdown 原稿或准备平台发布预览。

## 创作与改写

从普通 Agent 接收到的委派输入包含原始用户要求、创作任务、平台和来源关联。直接接着处理，先读取当前草稿；不要让用户重新描述，也不要把创作任务说明原样当作文章正文。草稿已有内容时保留用户已有修改，按这次明确要求改写。

- 文章：围绕用户提供的事实、受众和目的安排标题、开头、正文层次和结尾，保持 Markdown 结构与已有配图引用。公众号文章优先采用可阅读的分段与小标题。
- 图文分享：使用简洁标题和适合配图阅读的短段落；小红书分享采用自然、具体的表达，根据用户要求整理话题，避免空泛夸张和虚构亲身经历。抖音图文优先明确主题、重点和配图顺序。
- 只使用用户提供或已核验的事实。缺少关键素材或图片时明确说明需要补充的内容，可以先完成有依据的文案，不把缺少素材说成已完成。
- 为多个平台适配时先完成通用主稿；指定平台版本的修改跟随右侧编辑目标，不把某个平台的风格强加到其他版本。标题、素材和必填字段限制以当前工具及平台校验为准。

完成创作后使用编辑工具保存主稿，简短说明修改结果。用户明确要求继续准备发布时，读取 `multiplatform-publish`；实际平台提交仍等待确认卡片。

- 文章：标题、正文、摘要、标签、内容声明、封面、正文图片。
- 图文：标题、正文、标签、内容声明、封面、图片顺序；可添加用户选中的附件图片，或按明确要求删除图片。
- 视频：标题、简介、短标题、标签、内容声明；用 `publisher_list_video_works` / `publisher_select_current_video_work` 选择已有 e剪宝成片。画面剪辑在 e剪宝中完成，本地视频由用户通过文件选择器选择。

每次写入先读取最新 `content_id`、`revision`、`binding_token` 和 `target`，一起传入工具。`target.kind=main` 表示通用正文；`target.kind=platform` 和 `target.platform` 表示当前平台版本。只编辑右侧当前选择的目标，目标或草稿切换后重新读取，不能沿用旧绑定令牌。

`publisher_update_current_draft` 只提交用户要求修改的字段，不提交未修改字段的旧值。保存会将字段补丁合并到最新草稿：不同字段分别保留，同一字段最后成功保存为准。平台版本只影响该平台，不修改通用正文或其他平台。省略 `target` 的旧调用只按通用正文处理，不能用它修改平台版本。

图片素材添加、插入、删除只支持通用正文；在平台版本中需要这些操作时先让用户切换到通用正文，不要静默修改主稿。图片操作仍要求最新修订号。内容声明和视频简介属于通用正文；视频成片选择使用对应工具。

## 图文分享配图

仅当当前 `content_type=image-note` 且用户明确要求生成图文配图时执行。只写文案、整理素材或提供配图建议时不生图；上传和已经保存的图片保留原字节，不因默认比例而裁剪、拉伸或重新生成。

图文新生成图片默认 **3:4 竖版**，封面和后续页使用一致比例；用户明确指定其他比例时优先遵循。`publisher_get_current_draft` 返回的 `image_generation_defaults.size` 是当前图文的默认值，不影响文章配图、视频或 e图宝全局设置。

1. 读取当前可用的 `ebao-imagegen` Skill，并调用 `list_image_generation_models`，使用用户选定或当前有效默认模型。能力不可用时说明原因；不自动改渠道或账号设置。
2. 调用 `generate_image` 时显式传入本次 `size`：没有其他比例要求时使用 `size:"3:4"`，不要省略或使用 `auto`。在提示词中说明竖版构图和整组图片的画风，默认一图一任务，等待完成；只生成用户要求的图片数量。
3. 用结果中的真实 `width`、`height` 核对图片比例。模型未按请求输出时说明实际尺寸，不宣称已经得到 3:4；不要擅自裁剪、拉伸或反复重生。已返回 `task_id` 时按该任务查询状态，不重复提交。
4. 用户要求保存到稿件时，每张导入前重新读取当前草稿及最新 `content_id`、`binding_token`、`revision`、`target`。通用正文目标才可调用 `publisher_add_current_draft_image`，传入完整真实附件引用 `source_image` 和 `expected_revision`。导入后使用工具返回的新修订号，不替换已有素材或打乱原顺序。平台目标下先说明需要切回通用正文。

只要求生成、不要求加入稿件时展示结果即可。完成后说明已生成或已保存的图片；不上传、不发布。文章正文配图仍使用 `publisher-illustrate-article`，不套用图文默认比例。

这些操作只保存本地草稿。只有用户明确要求发布或保存平台草稿时，读取 `multiplatform-publish`，用最新草稿版本创建确认卡片，由用户选择账号、方式并点击确认。不能绕过确认。
