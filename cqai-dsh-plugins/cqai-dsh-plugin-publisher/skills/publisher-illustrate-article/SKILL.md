# 为当前文章配图

先调用 `publisher_get_current_draft`。返回 null 时停止，不搜索或新建其他文章、会话或工作区。只处理 `content_type=article` 且 `target.kind=main` 的文章；平台目标需要用户先切回通用正文，不暗中切换。保留当前标题、正文、已有图片及封面；只改变本次配图涉及的位置。本 Skill 不读取或改写写作偏好，不上传或发布文章。

## 确定配图用途

根据原文找出用图更容易理解的概念、流程、对比、关系或场景，为每张图确定目的与插入段落。数量遵循用户要求和实际解释价值，不默认每段一图，也不固定批次或张数。已有图片能满足要求时优先复用，不为了整齐重复生成。

用户只要配图方案、位置建议或提示词时，交付这些内容，不调用生图工具、不改正文。用户明确要求生成并给文章配图时可完成生图与插入；明确只生成、不插入时只展示结果。仅做封面的需求不在本 Skill 的正文插图闭环内，不承诺直接导入为封面，也不用先插正文再删除的办法规避限制。

整组图片保持画风、主辅色、线条和人物设定协调；按内容选择流程图、对比图、概念关系图或叙事插画。提示词写清主体、构图、信息关系、文章中的真实数字与短标签、必要比例和留白。不要照字面描绘与论点无关的比喻，不添加原文没有的事实。生成插画不能充当真实摄影、作者亲历或用户提供的证据。参考图只能通过当前实际支持的图片引用使用，不伪称已上传或读到参考文件。

## 使用 e图宝生成

通过当前原生 `skill` 工具发现并读取 `ebao-imagegen`，遵守其实际工具合同、启用状态、账号额度和模型限制。该 Skill 或工具不可用、未启用或被拒绝时，说明原因并交付可用的方案或提示词；不打开设置、不安装工具、不绕过限制。

调用 `list_image_generation_models` 取得当前模型目录。返回的 `selection=default` 或 `single` 可使用其有效默认值；`choice-required` 时只询问必要的渠道／模型选择；`unavailable` 时停止生成。第三方渠道只能按用户明确选择使用返回的 Provider 标识。登录、额度或请求失败时不自动改渠道、改账号设置或更换模型重试。

调用 `generate_image`，传入实际提示词和本次必要的 `size`、`count` 等工具支持参数；通常一图一任务，默认等待完成，不因可批量而多生成。使用用户指定的模型和比例，未指定时遵循当前有效默认值。已返回 `task_id` 时保存它；需要确认结果用 `get_image_generation_task` 查询，不重新提交来代替查询。超时或中断后检查真实状态，可能已失败或取消，不能一律当作仍在运行。失败、取消或生成质量不合格时如实说明，重生图可能再次计费，按用户新的重试要求执行。

只有真实 `completed` 结果的 `images[]` 才作为已生成图片使用。若当前工具能实际读取／查看图片，检查文字、布局及与原文的对应关系；仅有附件元数据时，不声称已经视觉验收。保留工具返回的完整图片附件引用，不把内部路径、访问链接或猜测的图片地址写入正文。

## 逐张插入最新正文

每份文章最多 20 个素材；根据最新草稿的 `assets` 数量控制剩余生成和插入数量。单图不超过 20 MiB，支持 `image/png`、`image/jpeg`、`image/webp`。不能改写 MIME 或虚构字节数来通过校验；不支持或过大的结果说明原因，不重复计费生成。

对每张准备插入的图片：

1. 再调用 `publisher_get_current_draft`。核对仍是同一 `content_id`、`binding_token` 和 `target`，且仍为文章的通用正文；若已切换或解绑，停止旧稿插入。使用这次读取的最新 `revision`、`body` 和已有素材，不使用出图前的旧全文覆盖用户刚做的修改。
2. 在最新 `body` 的适当位置加入恰好一个 `{{PUBLISHER_IMAGE}}`。除本次插入点外保留正文与已有引用。`alt` 用不超过 100 字符的简短图片说明，不含 `[]()` 或换行。
3. 调用 `publisher_insert_current_draft_image`，传入最新 `content_id`、`binding_token`、`expected_revision=revision`、`body_with_image_marker`、`alt`，以及来自生成结果该张图片的完整 `source_image`：`attachment_id`、`media_type`、`bytes`、`width`、`height` 和存在时的 `name`。不要自行拼接 `ebao-asset://` 引用，也不用通用正文更新工具代替图片导入。
4. 成功后才处理下一张，下一次仍重新读取正文。修订冲突时重读并重新合并插入点，复用已经生成的附件；若结果不确定，先检查正文与素材，避免重复插入。其他错误如实报告，不反复提交旧令牌或重新生图。

首次插图时若文章没有封面，当前插图工具会将首张图设为封面；已有封面保持。完成后简述实际插入数量与位置。部分成功时保留已保存的图，区分已生成、已插入、失败或取消的结果，不把方案、提示词或未完成任务当成配图已完成。

本文件为 Publisher 自包含适配版，配图定位与视觉一致性方法参考 MIT 许可的 baoyu-article-illustrator；工具闭环为本插件独立实现。来源、版本和原许可证随插件提供。
