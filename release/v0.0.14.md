# e宝工坊 v0.0.14

- 多平台发布改为原生按需 Skill：普通对话只提供简短入口，用户明确要求发布或编辑绑定草稿后，才加载对应流程和工具，不再全局追加完整发布提示词。
- 发布确认卡片按「核对内容 → 选择账号 → 确认方式」组织，默认折叠全文及其他账号，提交按钮明确显示方式和账号数量；仍由用户在卡片中确认后提交。
- 发布工具明确区分当前草稿和候选预览，校验来源、版本与绑定状态，内容变化、取消或异步准备失效时需重新确认；排队受理与平台执行结果分别展示。
- e图宝生成、编辑、查询、取消及模型目录改为原生按需 Skill，模型目录实时读取账号状态和默认模型；保留工作台、画布和 /edit_image 的直接操作入口。
- 生图与发布工具在回合结束、新用户请求或设置关闭时收回；普通子 Agent 不继承这些能力，用户显式运行的画布技能单独授权并随运行清理。
- 修复嵌套工具调用未交付 Skill 正文、首次斜杠调用工具目录不同步，以及提示词配置或多个 Skill 重组时的边缘问题。
- 发布前刷新 Stable、Beta、Next 的 dshmarket 最新精确版本及最新官方 Agents Anywhere main 桥接产物和来源记录。

Windows 构件没有 Authenticode 签名。本次 macOS 延续未签名测试预发布模式，请手动安装；不声明生产环境的就地自动更新支持。TalkCraft 使用 PolyForm Noncommercial 1.0.0。QQBot Connector 沿用仓库记录的精确版本单独授权。
