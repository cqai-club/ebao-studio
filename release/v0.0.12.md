# e宝工坊 v0.0.12

- 升级至官方 DeepSeek Harness 0.2.0-rc.2，并同步 Stable、Beta 和 Next 的运行时、插件市场及最新官方 Agents Anywhere 桥接产物。
- Stable 与 Beta 内置官方 Computer Use 插件。在“插件管理 → 已安装插件 → 官方”可查看状态并启用或停用；默认停用，设置可在重启后保留。实际使用仍需配置支持的模型及相应系统权限。
- 修复 Computer Use 原生 SDK 在 Electron ASAR 中的动态库路径，纳入 macOS universal、Windows x64 和 Linux 的原生文件检查，并增加最终打包程序中的 SDK 创建、工具目录读取与关闭检查。
- e图宝恢复普通生成与画布生成的全部记录总览，电商任务历史独立保存并支持恢复完整商品任务、查看逐图提示词；卡片按窗口宽度调整列数。
- 改进视频模型能力校验，修复短视频字幕代理环境和代理错误反馈。
- 一键发布增加对话中的发布确认和图文素材导入，避免未经确认直接发布。
- 发布流程统一为开发改动进入 dev、提升 master、打包校验成功后生成版本标签；发布文件保存提交、运行和校验值来源记录。

本版本沿用测试预发布模式。macOS 构件未签名，Windows 构件没有 Authenticode 签名。TalkCraft 使用 PolyForm Noncommercial 1.0.0。QQBot Connector 沿用仓库记录的精确版本单独授权。
