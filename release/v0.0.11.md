# e宝工坊 v0.0.11

- 数字人视频报价改为读取账户服务的 Relay 实时价格，明确显示获取进度、失败原因和费用确认提示，防止重复点击及使用历史估算提交生成。
- 修复小红书及多入口的登录状态误判，保留完整账号会话分区，并将无法确认的网络或访问状态显示为待确认。
- 修复应用私有 Python 3.11 检测参数冲突，解决包括 Windows 在内的平台下载后仍无法通过制作环境检查的问题。
- 恢复媒体运行库 uv 的执行权限，确保禁用依赖安装脚本时首次准备环境仍可运行。
- 修复 macOS ffprobe 的私有动态库加载，支持路径中的空格和单引号，并验证媒体工具复用与损坏修复。
- 支持 macOS、Windows、Linux 的系统字体发现，优先选择中文字体，修复短视频字幕提示找不到系统字体的问题。
- 在短视频当前任务记录中新增“打开文件夹”和“打开素材文件夹”，制作进行中也可查看已下载素材。
- Windows 发布前通过已打包的 Electron、uv 和 Python 脚本实际安装共享媒体工具及短视频锁定依赖，验证 Python、FFmpeg、ffprobe 和系统字体可用。
- 修复 Windows 发布验证未等待打包程序完成的问题，以实际安装验证的退出状态判断发布是否可继续。

本版本沿用测试预发布模式。macOS 构件未签名，Windows 构件没有 Authenticode 签名。TalkCraft 使用 PolyForm Noncommercial 1.0.0。QQBot Connector 沿用仓库记录的精确版本单独授权。
