# e宝工坊 v0.0.15

- 多平台发布使用独立 Agent 会话，打开会话时恢复对应内容，采用左侧对话、右侧内容的可调节分栏；支持增量保存、内容回收和恢复。
- 新增文章写作、润色、个人文风、平台改写和文章配图 Skill；文章与图片交接保留来源快照，发布委派按当前内容版本校验并避免重复执行。
- 发布设置与账号窗口按需加载，登录窗口在导航完成前即可显示；修复 Windows 隐藏或最小化账号窗口无法重新显示的问题。
- e图宝支持 3:4 图片比例，并对不支持该比例的模型使用兼容参数。
- 集成图片编辑、CQAI 账号模型设置和 Profile 安全诊断改进；社区市场新增受管插件更新与通知。E剪宝改为独立插件安装，桌面安装包不再携带其六个独立组件。
- Stable/Beta 按网络出口 IP 选择更新源：中国大陆使用 GitCode，其他地区和路由探测失败时使用 GitHub；Stable 从确认版本的同一来源下载并校验安装包。同步更新隐私政策与用户说明。
- macOS 安装包和更新 ZIP 的文件名去掉 `-universal`，保留 Intel 与 Apple Silicon 双架构。GitCode 同步原始七个发布附件，并保留旧版本文件名的校验兼容性。
- 刷新 Stable、Beta、Next 的 Market 精确依赖与最新官方 Agents Anywhere main 桥接产物、来源记录和锁文件。

Windows 构件没有 Authenticode 签名。本次 macOS 使用未签名测试预发布模式，请手动安装；不声明生产环境的就地自动更新支持。TalkCraft 使用 PolyForm Noncommercial 1.0.0。QQBot Connector 沿用仓库记录的精确版本单独授权。
