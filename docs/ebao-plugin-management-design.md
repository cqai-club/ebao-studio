# 插件管理设计

状态：统一入口、原生页面嵌入和预制插件扩展已实现；自动化测试与 Beta／Stable 构建通过。实际 Beta 界面和重启后的启停效果仍待运行验收。

## 入口和布局

- 将左下角账号菜单原「CQAI 插件市场」原位改为「插件管理」。点击后打开原生插件主面板，由自有外层布局承载，默认选中左侧「已安装插件」。CQAI Desktop 的主侧栏不再单独显示原「插件」入口。
- 页面采用左右布局：左侧只有「已安装插件」「插件市场」；右侧随导航切换。页面不显示 Profile 名称。
- 「已安装插件」直接渲染上游 Plugin Manager 页面，保留它的「官方／已安装」两组、安装、详情和配置。六个随 e宝工坊提供的功能通过扩展卡片与用户自行安装的插件共同显示在「已安装」，不另设分组；数量按实际清单计算。俱乐部活动由用户手动安装，显示为普通插件。
- 「插件市场」在右侧展示现有发现、搜索、详情、安装和来源配置。市场里的「已安装」入口返回左侧「已安装插件」，不再叠加市场弹层。

## 已安装内容

| 随包功能 | bundle 包名 |
| --- | --- |
| e图宝 | `cqai-dsh-plugin-imagegen` |
| e剪宝 | `cqai-dsh-plugin-video` |
| 多平台发布 | `cqai-dsh-plugin-publisher` |
| 口播视频制作 | `cqai-dsh-plugin-talkcraft` |
| 短视频制作 | `cqai-dsh-plugin-short-video` |
| PPT 制作 | `dsh-ppt-composer` |

- 按本版明确声明的包名识别随包功能；PPT 只显示 Composer 一张卡片。未随本版提供的功能不显示；清单读取失败时显示错误。
- 随包功能可以启停，但不能卸载；用户自行安装的插件沿用现有启停与卸载能力。基础服务（账号、管理入口、市场服务等）不提供停用或卸载。
- 同一插件只显示一次。列表和启停选择按活动 Profile、DSH_HOME 和发行通道隔离，但页面顶部不显示这些内部信息。

## 启停与重启

官方插件和用户自行安装的插件沿用当前操作规则。随包功能的开关保存下次启动选择，不会在本次运行中立刻卸载。卡片须区分「当前运行」「重启后停用」「已停用」「重启后启用」及「无法加载」。

停用前提示重启可能中断活动任务；保存后可撤销或重启。重启后以该次 Loader 组合的清单更新状态。停用不删除插件包、任务、草稿、凭据或历史；重新启用后恢复对应入口和能力。

## 实现边界

- 插件管理界面本身不新增独立插件包：由现有自有插件 `cqai-dsh-plugin-market` 承载账号菜单动作、左右布局、插件市场和随包功能卡片。六个随包功能及 CQAI 账号插件各自保留独立职责。
- 通过现有版本限定的 Yarn 补丁，为上游 Plugin Manager 增加外层承载槽和「已安装」卡片槽。上游页面与控制器保持唯一实例，其安装、详情、配置、启停和卸载流程原样复用；CQAI Desktop 注册外层布局并隐藏原侧栏入口，不复制整页代码。
- 外层布局没有注册或渲染失败时，恢复原生页面及原侧栏入口，保证插件管理仍可进入。
- Desktop Host 提供随包功能的实际清单与重启后启停接口。随包卡片只复用列表展示位置，不把功能伪装成用户安装的普通插件，也不调用上游普通插件的即时启停接口。
- `dsh-community-market` 复用现有市场内容并提供右侧嵌入接口；CQAI Desktop 模式下由统一入口接管原市场账号菜单动作。其他 Market provider 需要对应的页面适配；市场不可用时「已安装插件」仍可进入。
- Beta／Stable Desktop Host 只补随包功能清单、启停策略和必要的管理接口，使选择在下次启动的 Loader 组合中生效；市场 provider 切换不能重新加载已停用的功能。界面集中在自有插件，减少后续合并 Desktop 上游更新时的冲突。
- 兼容模式继续使用上游默认 Client，不修改 `deepseek-harness` 子模块；非 CQAI Desktop 环境仍直接显示原生插件页和侧栏入口。上游运行时升级时需校验版本补丁。
- 默认 Community Market 可嵌入右侧；切换到没有嵌入接口的 `dshmarket` provider 时显示市场不可用提示，已安装管理继续可用。官方配置项的详情就在同一原生页面打开。

## 验收

1. 账号菜单只有一个「插件管理」，主侧栏不再有旧「插件」入口；默认进入「已安装插件」，右侧为原生页面，保持「官方／已安装」两组，六个可用随包功能与用户插件同在「已安装」且无重复。手动安装俱乐部活动后只显示普通插件条目。
2. 随包功能停用后仍可见；重启后确实停止加载，再启用可恢复；账号和管理入口始终可用。
3. 「插件市场」在右侧可用，市场不可用时已安装列表仍可用；Beta 和 Stable 的实际加载状态与卡片一致。
