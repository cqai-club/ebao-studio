# CQAI Club 页面布局设计

状态：已按此布局完成本地实现；实际桌面界面仍待运行验收。

## 目标与入口

在截图标出的左下角账号菜单顶部新增 **「CQAI Club」**。点击后在当前桌面主窗口打开 CQAI Club 页面，整体结构参照现有「插件管理」：左侧固定分区导航，右侧显示所选内容。默认进入「积分信息」。

```text
左下角账号菜单（已登录）
┌──────────────────────┐
│ CQAI Club      ← 新增 │
│ 插件管理             │
│ 打开设置             │
│ 退出登录             │
└──────────────────────┘
```

未登录时，保留现有的「登录 CQAI Club」操作；「CQAI Club」入口仍可打开页面，积分信息区显示现有登录引导。

## 页面布局

```text
┌───────────────────────────── CQAI Club ─────────────────────────────┐
│                                                                    │
│  左侧导航                 右侧内容区                                │
│  ┌──────────────┐          ┌─────────────────────────────────────┐  │
│  │ ← 返回       │          │                                     │  │
│  │ ● 积分信息   │          │ 积分信息                            │  │
│  │   会员信息   │          │                                     │  │
│  │   俱乐部活动 │          │ [账户] [充值]   ← 现有内部切换     │  │
│  │              │          │ 当前账号                 已连接      │  │
│  │              │          │ 用户名 / 邮箱                       │  │
│  │              │          │ ┌─────────────────────────────────┐ │  │
│  │              │          │ │ 剩余额度  [沿用当前单位与格式]  │ │  │
│  │              │          │ └─────────────────────────────────┘ │  │
│  │              │          │            [刷新账号] [退出登录]   │  │
│  └──────────────┘          └─────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

- **左侧**：按「积分信息 → 会员信息 → 俱乐部活动」竖向排列。选中项使用与插件管理一致的底色和字重；切换时只更新右侧内容。
- **右侧**：页面标题位于顶部，内容在下方滚动。沿用当前应用的浅色／深色主题、卡片、边框和按钮样式，不另设一套视觉语言。
- **宽度**：左侧导航参考插件管理的约 184 px；窄窗口可缩至约 150／120 px。右侧内容随窗口伸缩，额度卡片与账号字段可换行，避免横向滚动。

## 三个分区

| 左侧入口 | 本阶段右侧内容 | 交互 |
| --- | --- | --- |
| 积分信息 | 使用原账号页的身份、剩余额度和充值内容。账户／充值继续使用现有的内部切换；保留刷新账号、退出登录、充值和最近充值记录等已有操作。 | 打开 CQAI Club 时默认选中。额度数值和单位沿用当前账号数据，不把额度写成现金余额。 |
| 会员信息 | 仅显示「会员信息」标题，下方内容区留白。 | 可以切入并保持选中状态；本阶段没有会员等级、权益或按钮。 |
| 俱乐部活动 | 由独立活动插件提供内容；未安装或未启用时显示说明。 | 可以切入并保持选中状态；账号插件不自行请求活动数据。 |

会员信息区的留白是有意的：不显示虚构数据，也不放「敬请期待」等占位文案。

## 交互与状态

1. 点击账号菜单「CQAI Club」后关闭菜单，进入该页面并选中「积分信息」。再次从账号菜单进入，也回到「积分信息」。
2. 点击左侧顶部「返回」回到会话主界面；插件管理页面提供相同位置、相同行为的返回按钮。
3. 切换三个分区时，左侧导航保持可见，页面不叠加第二层弹窗；返回其他主页面后可以通过账号菜单重新进入。
4. 未登录、授权中、登录失效、读取失败等情况，积分信息区沿用现有账号页面的提示与操作；不把未知额度显示为 `0`。
5. 会员信息在上述账号状态下仍保持空白内容。俱乐部活动由独立插件决定内容；未安装或未启用时显示说明，账号插件不额外请求或假设活动数据。

## 本稿确认点

- 新入口位于截图红框位置，在「插件管理」上方。
- 新页面使用与插件管理相同的左右布局，首屏是「积分信息」。
- 现有账号、额度和充值能力进入首屏；会员信息先为空白，俱乐部活动由独立插件提供。
- 页面由 CQAI 账号插件提供；本稿记录布局与交互，不包含实现细节。
- Stable/Beta 的设置页不再重复显示 CQAI Club；实验性 Next 暂时保留设置入口，因为尚无对应的主页面。
