# Agent Note：新版桌面通道与私有共享源码

Status: implemented

[English](2026-11-04-modern-desktop-channels.md) | 中文

## 决策

产品采用 `anywhere-labs/dsh-desktop` 提交 `117e4899132553b230cafd902d78c0f8f0020132` 的新版独立 Host 架构。用户明确选择将 Stable 和 Beta 都迁移到该架构。Stable/Beta 继续保持自有源码镜像，仅保留声明的产品身份差异；Next 仍为独立实验通道。

三个应用通道统一使用官方 Harness 提交 `8bd073392eef6f54e921a093b95076248eb08cbb` 构建的 `0.2.2-alpha.3` 运行时。官方源码仍是未修改的 Git 子模块，其固定提交在桌面整合前独立提交。通过官方构建、打包命令生成 vendored 产物，清单记录实际源码提交和校验值。桌面兼容修复保留为外层仓库的版本化补丁。

新壳仍使用原 Stable 实现中的原生控件与工具。这些导入改为指向私有 `dsh-desktop-shared` 工作区，不再依赖其他发布通道的实现。共享工作区不声明应用入口、包导出或 DSH bundle；构建依赖与各应用通道使用同一官方运行时家族，也不加入用户 Profile 的 bundle 列表或应用生产依赖。

## 产品能力

Stable/Beta 将现有 CQAI 账号、图片、发布、市场和展示能力组合为应用自有层。在 Profile 操作和 HMR 重组时保留这些层，不向用户清单持久化桌面壳入口。安全模式不加载产品能力。新版官方前端负责主界面；原高级模式展示层仅在其旧模式条件下启用。

受限的 Host 到主进程桥接提供这些层所需的 CQAI 账号和 Publisher 服务。发布 Worker 方法继续使用白名单；原生视频选择返回不透明句柄；Host 释放时取消请求，应用关闭时停止 Worker。共享源码复用现有 Publisher supervisor，不引入第二套 Worker 协议。

## 验证

运行时打包前必须通过官方 Harness 构建。验收还包括根工作区不可变安装、运行时来源与补丁重放检查、Stable/Beta 同源检查、自有包的无图形界面检查，以及单独显式启动图形应用。无图形界面检查通过不代表安装包或真实账号发布流程已验收。

## 影响

当前官方运行时要求 Node 24.9 或更新版本。根 Yarn 与上游 pnpm 的边界保持不变。后续共享控件修改归属 `dsh-desktop-shared`，应用行为仍归属对应的新桌面壳。不得恢复跨通道实现导入，也不得把共享源码变成可加载插件。
